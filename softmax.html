def get_CIFAR10_data(num_training=49000, num_validation=1000, num_test=1000, num_dev=500):
    """
    Load the CIFAR-10 dataset from disk and perform preprocessing to prepare
    it for the linear classifier. These are the same steps as we used for the
    SVM, but condensed to a single function.
    """
    # Load the raw CIFAR-10 data
    cifar10_dir = 'cs682/datasets/cifar-10-batches-py'
    # Don't forget to run get_datasets.sh, or this will throw an error
    X_train, y_train, X_test, y_test = load_CIFAR10(cifar10_dir)

    # subsample the data
    mask = list(range(num_training, num_training + num_validation))
    X_val = X_train[mask]
    y_val = y_train[mask]
    mask = list(range(num_training))
    X_train = X_train[mask]
    y_train = y_train[mask]
    mask = list(range(num_test))
    X_test = X_test[mask]
    y_test = y_test[mask]
    mask = np.random.choice(num_training, num_dev, replace=False)
    X_dev = X_train[mask]
    y_dev = y_train[mask]

    # Preprocessing: reshape the image data into rows
    X_train = np.reshape(X_train, (X_train.shape[0], -1))
    X_val = np.reshape(X_val, (X_val.shape[0], -1))
    X_test = np.reshape(X_test, (X_test.shape[0], -1))
    X_dev = np.reshape(X_dev, (X_dev.shape[0], -1))

    # Normalize the data: subtract the mean image
    mean_image = np.mean(X_train, axis = 0)
    X_train -= mean_image
    X_val -= mean_image
    X_test -= mean_image
    X_dev -= mean_image

    # add bias dimension and transform into columns
    X_train = np.hstack([X_train, np.ones((X_train.shape[0], 1))])
    X_val = np.hstack([X_val, np.ones((X_val.shape[0], 1))])
    X_test = np.hstack([X_test, np.ones((X_test.shape[0], 1))])
    X_dev = np.hstack([X_dev, np.ones((X_dev.shape[0], 1))])

    return X_train, y_train, X_val, y_val, X_test, y_test, X_dev, y_dev

Inline Question 1:¶

Why do we expect our loss to be close to -log(0.1)? Explain briefly.**

Your answer: In the lecture notation the scores are $z_j = W_j x_i$, the softmax gives $p(y = i \mid x) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$, and the loss is $L_i = -\log\left(\frac{e^{z_{y_i}}}{\sum_{j=1}^{K} e^{z_j}}\right)$.

$W$ is initialised with very small random values ($\times 0.0001$), so every $z_j \approx 0$. Then each $e^{z_j} \approx 1$ and, with $K = 10$ classes, $p(y = y_i \mid x) \approx \frac{1}{10} = 0.1$. Therefore $L_i \approx -\log(0.1) = \log 10 \approx 2.303$, and the average $L = \frac{1}{N}\sum_i L_i$ (no regularization here) is the same. This is a sanity check that the loss is implemented correctly.

Inline Question - True or False

It's possible to add a new datapoint to a training set that would leave the SVM loss unchanged, but this is not the case with the Softmax classifier loss.

Answer: True

Explanation: For the SVM, $L_i = \sum_{j \ne y_i} \max(0,\ s_j - s_{y_i} + 1)$ is exactly 0 whenever the correct score beats every other score by at least 1, i.e. $\mathbb{1}(J) = 0$ for all $j$. So we can add a new point that the current $W$ already classifies correctly with that margin; it contributes 0 to the summed data loss and 0 to the gradient.

For softmax, $L_i = -\log\left(\frac{e^{z_{y_i}}}{\sum_{j=1}^{K} e^{z_j}}\right)$. Because every $e^{z_j} > 0$, the probability $p(y = y_i \mid x) < 1$ for any finite scores, so $L_i > 0$ always. Every new point therefore adds a strictly positive amount to the softmax loss.

(Strictly, since $L = \frac{1}{N}\sum_i L_i$ is an average, adding a zero-loss point rescales the SVM average by $\frac{N}{N+1}$. The key idea is that the new point itself contributes zero hinge loss but always a positive softmax loss.)
